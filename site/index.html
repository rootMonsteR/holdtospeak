What it does

Works where dictation usually breaks.

Cloud dictation ships your microphone to someone else's computer — a non-starter under an NDA, and unnecessary: a modern speech model runs comfortably on a normal CPU.

Types into the apps that usually break

Terminals, WSL, IDEs, browsers, chat apps, remote sessions — a per-target injection chain, not clipboard-paste-and-hope.

Never rewrites your commands

Focused on a terminal or code editor? Dictation drops to verbatim automatically, so kubectl get pods -n kube-system stays exactly that.

Refuses password fields

The focused control is checked live through UI Automation. If it is a credential field, nothing is typed — ever.

Learns your jargon

learn cube ctl => kubectl and it is fixed permanently — in a plain-text file you can read and edit.

Tells you when it can't help

Elevated window? You get "text kept, not inserted" and a key to paste it yourself — never a silently swallowed sentence.

Never clips your first word

The microphone runs in a 400 ms look-back ring, so the utterance starts when you do — not when the app catches up.

How it works

Everything happens on your machine.

Hold Ctrl + Win

A pure Win32 keyboard hook opens the channel; the overlay appears. The Start menu never pops, and Ctrl+Win+Arrow still switches desktops.

Speak

Audio goes into an in-memory ring — with 400 ms of look-back from before the key press.

Release

Local speech recognition (NVIDIA Parakeet, on the CPU) turns it into text; deterministic cleanup tidies it.

Text at the cursor

Inserted through the route that works for the focused app — terminal, browser, RDP, or anything else.

Raw

Exactly what you said, plus your dictionary. Forced automatically in terminals and IDEs.

Auto

Light tidy: um/uh removed, sentence casing, terminal punctuation.

Polish

Auto plus conversational scaffolding removed — "like, you know, and stuff" gone, meaning intact.

All three are rule-based and run entirely offline, so they can only ever delete filler — they can never invent or reword anything.

Overlay

Four looks, one message.

Every theme tells you the same three things — the mic is being heard, which cleanup mode is on, how strong the signal is. Picking one changes how it looks, never what it tells you.

HUDdefault — tactical comms: voiceprint, timecode, mode callout
Voltan electric beam with lightning forks that ride your voice
Waveflowing layered waveform, tinted by the active mode
Barsfrequency spectrum — the classic visualizer

Cycle live with Ctrl + Alt + O or from the tray icon; set a default with overlay_style in %APPDATA%\HoldToSpeak\settings.toml.

Privacy

Built to be checked, not trusted.

No account, no cloud, no telemetry. There is no server behind this app and no code path for analytics or crash reporting.

One network request, ever. The first run downloads the ~460 MB speech model from its upstream GitHub release and verifies it against a pinned SHA-256. That is the only outbound HTTP in the codebase.

Recordings don't stick around. Audio is transcribed from a temporary file that is deleted immediately afterwards.

No screenshots, no reading your documents. It sees the name of the focused app and whether the field is a password field — enough to choose how to insert text, nothing more.

The full statement, including exactly what is stored where: PRIVACY.md.

0outbound connections

Prove it in one line. After the model is installed, block the app from the network entirely — dictation keeps working.

# admin PowerShell
New-NetFirewallRule -DisplayName "Block HoldToSpeak outbound" `
  -Direction Outbound -Action Block `
  -Program "$env:LOCALAPPDATA\HoldToSpeak\HoldToSpeak.exe"
Unplug the cable and use it normally
Watch it in Wireshark or Resource Monitor
Read the code — one URL, in one crate
Delete two folders and it's gone clean
Hotkeys

Four keys to learn. They work in any app.

Ctrl+Win (hold)Dictate — speak, then release.
Ctrl+Alt+MCycle cleanup mode: Raw → Auto → Polish.
Ctrl+Alt+OCycle overlay theme.
Ctrl+Alt+QQuit.

Rebind any of them in %APPDATA%\HoldToSpeak\hotkeys.toml — plain text, off disables one.
